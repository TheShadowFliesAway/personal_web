# Papertrail · 私人学习空间

一个仅供个人使用的论文与学习笔记网站。云端运行目标为 **Vercel Hobby + Turso Free + Cloudflare R2 Standard**，不需要租赁服务器。

## 已实现

- 论文库：arXiv / 其他原文链接、年份、摘要、标签、记录状态、近期常看、搜索与列表 / 卡片视图。
- 论文记录状态：未开始记录 / 记录中 / 记录完成。标签支持下拉多选、搜索、新建和跨笔记复用；卡片上的 × 只取消当前关联，标签管理仅允许删除未使用的标签（引用数量包含回收站）。标签库随 JSON 备份导出与恢复。
- 主页以最近编辑、快速记录和近期常看为主；论文记录进度单独展示。学习笔记不显示状态，按主题和编辑时间组织。
- 研究路线：论文节点拖拽、带说明的有向连线、分支和汇合、关系列表。同一论文可以加入不同路线，内容只有一份。
- 学习笔记：主题路径（`编程与工具/PyTorch`）、标签，以及论文 / 笔记双向关联展示。侧边栏齿轮或“管理主题”可删除主题及子主题，笔记（含回收站中的笔记）保留并移到“未分类”。
- Notion 风格块编辑器：中文斜杠菜单、拖动区块、选中文字格式化、表格、待办、代码高亮、图片。
- Markdown 源码模式与 `.md` 导入 / 导出；导入会追加正文，不覆盖已有内容。
- LaTeX 公式：插入代码块，将语言选为「LaTeX 公式」即可预览。
- 自动保存、跨页面导航前保存、未保存离开提醒、乐观并发检查、历史版本和回收站。
- 单个个人密码登录；持久化登录限流；所有数据和图片接口检查会话。
- R2 图片压缩、私有读取、应用上传容量限额；JSON 数据备份导出。
- 适配手机访问；`Ctrl / Cmd + K` 搜索，`Ctrl / Cmd + S` 保存；文章和路线拥有可收藏的 URL。

## 本地开发预览

需要 Node.js 22.13+。这是开发 / 验证流程；正式使用的数据在云端，不依赖开发电脑。

```bash
npm ci
cp .env.example .env.local
npm run dev
```

打开 `http://localhost:3000`。`.env.example` 的 `DEMO_MODE=true` 只在非生产环境生效，演示数据保存在忽略提交的 `.data/demo.db`。包含少量 CLIP / BLIP / BLIP-2 与学习笔记示例，方便检查体验。

正式部署 **始终禁用演示模式**，未配置云数据库与登录密钥时只显示配置提示，不开放数据。正式数据库从空白开始；演示内容不会自动上传。

## 云端上线

按照 [DEPLOY.md](./DEPLOY.md) 创建 Turso 数据库、R2 存储桶、配置 Vercel 环境变量。账号注册完成后仍需要创建具体资源。

```bash
npm run auth:setup
```

交互生成密码哈希与会话密钥。密码输入不回显；生成结果只填入环境变量，不提交到仓库。

## 验证

```bash
npm run typecheck
npm test
npm run build
npm run test:production
# 另一个终端运行 DEMO_MODE=true npm run dev 后：
npm run test:e2e
```

浏览器测试默认使用 Playwright 自带 Chromium；可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指向已安装的 Chrome。没有浏览器时先运行 `npx playwright install chromium`。测试只针对开发演示库，不能连接正式用户数据。

## 数据与边界

- 正文同时保留 BlockNote JSON 和 Markdown。块 JSON 保留完整编辑结构；标准 Markdown 不支持的样式（文字颜色、折叠状态等）在源码编辑后可能丢失。普通标题、列表、代码、图片和表格可转换。
- LaTeX 当前通过 `latex` 围栏代码块预览；不是完整的任意 `$...$` 行内数学扩展。
- 自动保存约在停笔 900ms 后触发。发生跨设备版本冲突时不覆盖远端，保留编辑内容并提示导出、刷新。首次编辑产生历史快照，之后连续编辑约每 5 分钟一个，最多 20 个。
- 图片最大原图 20 MB，浏览器压缩到 3 MB 内、长边 2400px，服务端解码为 WebP 后存储；不支持 PDF 或任意文件上传。
- 图片 URL 在正文内是稳定的 `/api/images?id=…`。该接口验证会话后生成 5 分钟有效的私有下载地址。导出的 Markdown 中图片地址仍依赖原站点，迁移时需要单独复制图片并重写地址。
- JSON 备份包含文章、主题、路线、历史快照和图片清单，不包含图片二进制。当前提供管理脚本恢复 JSON；详见部署文档。备份不是云端定时任务，需要定期下载。
- 回收站内容不会自动清除；路线中的归档论文显示为已归档。路线删除不删除论文。图片暂不自动清理，避免误删历史版本仍引用的图片。
- 应用上传容量限制不是服务商账单硬上限；图片请求费、税费及政策变化仍需查看平台账单。默认 1 GiB 上传容量适合小规模起步。

## 技术栈

Next.js / React / TypeScript；BlockNote；React Flow；Turso（libSQL）；R2（S3 API）；Sharp。所有访问密钥仅在服务端使用，不使用 `NEXT_PUBLIC_` 前缀。

近期常看按最近 30 天的打开次数自动排序，同次数按最近访问时间排序，30 分钟内重复打开计一次。访问统计独立于正文，不改变编辑时间；历史收藏数据保留但不再作为界面入口。

### 数学公式

在 Markdown 模式中使用独立的 `$$…$$` 公式块（支持同一行或分行），切换到块编辑查看公式。直接向普通段落粘贴包含公式的 Markdown 也会识别；代码块内部保持原样。公式转换为可编辑的 `latex` 代码块，下方显示 KaTeX 预览；保存或导出后可能以 LaTeX 代码围栏形式表示。Markdown 模式本身是源码编辑器。

```text
$$
\frac{a}{b} = \sum_{i=1}^{n} x_i
$$
```

目前此输入方式针对独立公式块，不解析正文中的单美元符号行内公式。
